## 🎂 What is Birthday Love?

**Birthday Love** is a beautiful, interactive 5-page website to celebrate someone special on their birthday!

---

## ✨ Features

### 📄 5 Amazing Pages:

1. **🎉 Welcome Page** - Sweet introduction with animated teddy bear
2. **📸 Photo Gallery** - Upload up to 6 beautiful photos
3. **💌 Love Messages** - 6 heartfelt birthday wishes
4. **🎂 Cake & Candles** - Interactive cake with confetti celebration
5. **💕 Final Wishes** - Special closing message with wish categories

### 🎨 Beautiful Design:
- 🌈 Purple gradient theme
- ✨ Smooth animations & transitions
- 📱 Fully responsive (mobile, tablet, desktop)
- 🎬 Interactive effects

### 🎊 Fun Features:
- 📷 Upload photos easily
- 🕯️ Blow animated candles
- 🎉 Confetti explosion effect
- ❤️ Pre-written love messages
- 🎯 Easy navigation

## 🎯 How to Use

### Adding Photos:
1. Go to **Page 2: Photo Gallery**
2. Click on photo boxes
3. Select images from your computer
4. Done! Photos appear instantly

### Blowing Candles:
1. Go to **Page 4: Cake & Candles**
2. Make a wish 💭
3. Click **"Blow Candles"**
4. Watch confetti explosion! 🎊

### Navigation:
- **Next →** - Go forward
- **← Back** - Go backward
- **🔄 Start Over** - Restart

---

## 🎨 Customization

### Change Theme Color:
1. Open `style.css`
2. Find `#667eea` (purple)
3. Replace with your color
4. Save and refresh

### Edit Messages:
1. Open `index.html`
2. Find message text
3. Edit to your wishes
4. Save and refresh

### Add More Photos:
1. Open `index.html`
2. Duplicate photo boxes
3. Add to page 2
4. Save and refresh
